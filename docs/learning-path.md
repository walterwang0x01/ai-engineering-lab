## 怎么用这份路线

- **按顺序读**。每篇标了前置依赖，跳过前置可能看不懂。
- **遇到关卡就停下来做**。6 个关卡是交互式的，比纯读笔记有效得多。
- **标注**：必读 = 地基，选读 = 有用但非前置，按需 = 遇到问题再查。
- 预计总时长约 25–30 小时（不含 Agent 模块的按需部分）。
